# 2.4 Juice: slow-mo, конфетти, скриншейк

Статус: QUEUED (ждёт 2.2; параллельно с 2.3).

## Цель

Бросок «залипает», но результат всё равно читаем за ≤3 сек (жёсткий бюджет из UX_ROLL.md §3 — juice,
бесящий на 50-м броске за вечер, хуже его отсутствия).

## Контекст

- `docs/UX_ROLL.md` §3 (таблица техник), `docs/AUDIO.md` (звук уже есть: rattle + thock + mute).
- Есть: `features/roll-dice/sound.ts`, сцена и камера OrbitControls в `shared/three/table.ts`
  (бывший `viewer.ts` удалён 2026-10-07 — 0 потребителей).

## Требования

1. **Slow-mo nat20/nat1** — timeScale физики ×0.25 на последние ~0.5 сек полёта при натуральных 20/1
   (d20). Реализация: множитель шага в пампе мира; предсказание не нужно — замедляем хвост любого
   броска d20.
2. **Конфетти на крит** — `THREE.Points` (~200 частиц, 1.2 сек, затем dispose). Только nat20 (не
   каждый бросок).
3. **Скриншейк ∝ числу костей** — амплитуда от `parts.length`, затухание 300 мс; выкл при
   `prefers-reduced-motion` (уже уважается для автоповорота).
4. **Звук**: фанфары крита / грустный тон nat1 (AUDIO.md, арпеджио треугольником).
5. Всё за флагами/единым `juice`-конфигом, чтобы выключалось одним местом (эко-режим PERF.md позже
   переиспользует).

## Файлы
