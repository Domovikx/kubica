# 2.10 mtable-hint: красивый empty-state хинт (ресёрч + UI)

Статус: DOING (второй заход по фидбэку; v1 «пузырь у кнопки + пульс» отклонена)

## Обратная связь пользователя (доработка; итог ревью v1)

Реализация из этого блока (пузырь под шапкой + моргающая кнопка) — **выглядит ужасно с точки зрения
UX/UI, бесит**. Уточнения и требования:

1. **Центрированное сообщение на экране.** Изначальная идея была: спокойное уведомление по центру,
   без анимации. Когда костей нет — центр экрана свободен, его и используем.
2. **Copy — красивое, лаконичное, для пользователя**: (а) быстрый намёк «добавь кости, жми такую-то
   кнопку»; (б) короткая лаконичная информация о программке (что это за приложение) — вперёд слот
   под монетизацию (не сейчас, но структуру под это место оставить).
3. **Анимация — минимальная или лучше убрать полностью.** Моргающая кнопка (пульс `hintPulse`)
   убрать обязательно; любая новая анимация только если она точно не бесит (фейд при появлении —
   допустим, «дыхание» — нет).
4. Сначала **исследование**, как сделать сообщение на основном экране приятным (не раздражающим
   empty state), затем реализация.

## Цель

Хинт при отсутствии костей на столе — хорошая идея, но сейчас это «голая» кнопка (серый текст 15px
по центру, top 42%). Сделать **продуманный и красивый UI**: типографика, разметка, положение,
состояния — сначала ресёрч паттернов, потом дизайн (2–3 варианта на выбор человеку), потом
реализация.

## Ресёрч (старт, расширить)

- **Empty state** (Mobbin, Carbon, Pencil&Paper): первый экран — это onboarding-момент;
  action-focused паттерн = короткий copy + primary CTA; copy — одна фраза + подфраза, без инструкций
  «в две строки через запятую».
- **Coach mark** (NN/g, Chameleon, TYPENORM): anchored callout **указывает на конкретный контрол**
  (пузырь с хвостом к кнопке), spotlight + одна фраза, исчезает после первого действия; NN/g
  предостерегает от стены оверлеев — один намёк, не тур.
- Варианты компоновки на выбор:
  1. **Пузырь у кнопки** «+ Кости» (шапка, центр) — хвост вверх, стрелка/пульс-анимация кнопки, тап
     по пузырю → шторка;
  2. **Центральный empty-state блок** — крупная композиция из die-glyph (CSS-кости), заголовок +
     подстрока + явная кнопка «+ Кости» (action-focused);
  3. Гибрид: тихий текст в центре + pulse-кольцо на кнопке (самый минимальный).

## Требования

1. Ресёрч → 2–3 мокапа/варианта (можно в tmp-скриншотах на реальной странице), выбор человека;
   только потом код.
2. Типографика по гайду (заголовок ~17–18/700, подстрока ~13/600 `#9aa0aa`, не мельчить на 320px;
   адаптив — не ломать шапку).
3. Состояния сохранить: пусто (интерактивно → шит), грузится (disabled, текст статуса), ошибка
   загрузки; после появления костей хинт исчезает (сейчас так и есть — проверить).
4. Тап по хинту открывает шторку; `role`/`aria-label` живые (кнопка, не див).
5. Мобильный жест не конфликтует: хинт не перехватывает pan/tap по канве (он вне canvas, в `.mtable`
   — проверить z-index/pointer-events).
6. CSS-анимации лёгкие (transform/opacity, respect `prefers-reduced-motion`).

## Приёмка

- Скриншоты пустого стола на 320/390/768: хинт читается, не обрезается, не конфликтует с

- Текст/кнопка существующие e2e не ломают (`npm run test:e2e` — точечно `m-table.spec`), 0 ошибок
  консоли.
- Состояния loading/error визуально оформлены (не серый текст без chrome).
- `tsc`, eslint, `npm test` зелёные; после правки — напомнить про перезапуск opencode, если тронут
  `.opencode/` (не трогаем).
