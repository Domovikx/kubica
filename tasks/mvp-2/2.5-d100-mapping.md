## Цель

`d100` бросается как два d10 (десятки 00–90 + единицы 0–9), результат 0–99 (00+0 читается как 100 —
стандарт D&D). Плюс машиночитаемая карта граней.

## Требования

1. **Симуляция d100** — в `features/dice-pool/pool.ts` (из 2.2): при `sides === 100` бросать две
   кости d10 (два тела в том же мире), `tens = reading×10`, `units = reading`; total = tens+units;
   `00+0 → display '100'`, иначе `String(total)` (ведущий ноль у единиц не показываем: `70`, не
   `70`... пример: tens=70, units=0 → `70`). Точнее: display = total === 0 ? '100' : String(total).
2. **Визуал**: обе костиd10 кувыркаются (две панели? нет — один бросок, один поп; детали оставить на
   усмотрение: минимум — поп `d100 → 73 (70+3)`).
3. **mapping.json** — новый артефакт `assets/mapping.json`:
   `{ "d4": {"faces": 4, "values": [1,2,3,4], "oppositeSum": null}, ... }` для всех шести костей +
   `d100`. Тест: файл валиден, суммы совпадают с `geometry.ts` (генерировать из него же, не
   руками!).
4. Тесты: `d100` в диапазоне 1..100 (display), детерминированные пары (tens/units → total) на моках,
   mapping.json снапшот-тест.
