# 2.3 Подсветка kept/dropped, сумма + разбивка

Статус: QUEUED (ждёт 2.2 — поле `parts` в результатах пула).

## Цель

При advantage видно ОБЕ кости, удержанная подсвечена; поп результата показывает сумму и разбивку
(`17 [12+5]`, дропнутое — приглушено).

## Контекст

- `docs/PLAN.md` → Трек A, задача 2.3.
- Есть: `.result`-поп (`shared/ui/result-pop.ts`, стили `.result/.resultSum` уже зарезервированы),
  `HistoryEntry.parts` из 2.2.

## Требования

1. Расширить поп: строка суммы + строка разбивки (`12 + 5`, kept жирным/ цветным, dropped —
   `opacity ~0.4` + зачёркивание или метка `drop`).
2. История: каждая запись показывает сумму и части; реролл повторяет то же выражение пула (не
   одиночную кость).
3. Accessibility: разбивка дублируется текстом для screen reader (`aria-live` уже есть для
   результата — расширить).
4. Тесты: рендер разбивки на фикстурах частей (без DOM — pure-функция форматирования
   `formatParts(parts): string[]` + unit-тесты).
