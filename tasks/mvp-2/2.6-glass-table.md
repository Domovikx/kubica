# 2.6 Общий стеклянный стол: мультивыбор костей (старт: д4+д6)

Статус: DOING (прототип ?glass; эталоны одиночек из 2.2–2.3 не трогаем).

## Цель

Одни стол — одна камера снизу — N костей: тап/кнопка бросает ВСЕ выбранные кости сразу в одном
физическом мире (кувыркаются вместе, стукаются друг о друга — честная горсть), после остановки
разъезжаются по слотам в центр. Старт-кейс: д4+д6 как эталон пары; дальше по МВП: N костей →
пул+пресеты на столе → juice.

## Контекст

- Стекло и чтение низа: `src/shared/three/viewer.ts` (`glass`/`below`),
  `readBottomRoll`/`readD4ScreenTop`/`resolveD4Below` (`features/roll-dice/readout.ts`),
  `quatForValueDown` (face-orient). Одиночный стол-панель — `widgets/viewer-grid/`.
- Пул-логика (сумма+части+история) уже есть headless: `features/dice-pool/pool.ts` (2.2/2.3). Стол —
  её визуальное исполнение, не второй движок.
- Поп — синглтон (`shared/ui/result-pop.ts`): паре показываем общий поп «д4+д6 = сумма + части»
  (паттерн 2.3), а не два попа друг на друге.
- Архитектура: виджет→виджет импорты запрещены — выбор «сетка vs стол» живёт в `pages/home/home.ts`
  (слой pages).

## Требования

1. **Одна сцена**: `shared/three/table.ts` (`createTable`) — renderer/сцена/камера снизу, свет
   сверху + подсветка снизу (`under`), поверхности нет. N мешей GLB (scale в размер физ-тела,
   creased-нормали — как витрина).
2. **Один мир**: `features/table-roll/` — свежий rect-мир на бросок, конкурентные `world.roll` (тела
   сталкиваются — горсть честная), чтение низа (д6 — `readBottomRoll`, д4 — `resolveD4Below`), общий
   лейбл `д4+д6`, сумма, одна запись истории + один поп с частями. Осевшие остаются статикой до
   конца пачки (место занято); мир чистится целиком после броска.
3. **Виджет** `widgets/glass-table/`: док с картами костей (тач-зоны 44px, тап по карте = +1,
   счётчик N) + большая красная кнопка «Кинуть • N»; тап по любой кости тоже бросает всех. Набор —
   стор `features/table-setup/` (счётчики, капы 8/10, персист; `?glass=д4,д6` — пресет в него).
   Инстансы `д6#0…` (меш/тело/чтение на ключ). Слоты после settle: `layoutSlots(n, gap)` (шаг — от
   самой крупной кости), кадр — `glassHalves`. Сайдбар в table-режиме — только история (home не
   монтирует чекбоксы/пул).
4. **Физика пачки** (`features/roll-dice/physics.ts`, общее с одиночками): покой = опора (контакт) +
   тишина — сон в воздухе не засчитывается; тихое пересечение растаскивается (`separation`),
   затяжное (>2 с) — тоже; спавн с зазором над осевшей статикой (иначе взрыв депенетрации); опора,
   исчезнувшая из-под спящего, — побудка остальных.
5. **Ретраи поснапно, а не всей пачкой**: таймаут — докидываем только незасевших (max 2 раунда, из
   слотов), осевшие стоят; статус «Докатываю…» виден на кнопке + `[table] retry` в консоли.
6. **Энергия пачки** (замер: марафоны круглых д10/д12): швырок ниже при большем N (28/24/21),
   `damping 0.3`, глухой фетр (0.9/0.05), хватка качения (9/6), тяга фетра в контакте (2.0/3.0), сон
   охотнее (1.0). Полёт баллистический — не тронут. Гравитацию в конце НЕ крутим: сильнее гравитация
   — короче кувырок — меньше перемешивание (риск смещения); честность держится хаосом initial. Хвост
   ~4% закрывает поснапный ретрай; сильный момент/тяга — регресс (раскачивают связки, проверено
   замером).
7. **Пересечение — точный тест** `diceOverlap` (вершина строго внутри тела; все грани плоские):
   дистанция ловит глубокое, вершины — угловое; касание грань-в-грань — не пересечение. Счётчик с
   гистерезисом против фликера.
8. **Презентация одним движением** (урок д6 «не в ту сторону»): full-slerp сразу на финальную позу
   (низ ровно + цифра прямо), без двухфазных доворотов. Ретраи как у одиночек: таймаут/cocked →
   переброс (max 2).
9. **URL**: `?glass=д4,д6` (список через запятую) → стол; одиночный `?glass=д6` → старая панель
   (эталон). Пустой/битый список → первая выбранная (как раньше).
10. **Не ломаем**: одиночные панели, миры hex/rect одиночек, пул headless.
