# 2.12 Баг: белая полоса на рёбрах d20 (исследование)

Статус: DONE — приоритет НИЗКИЙ; вердикт: фича (скругление рёбер), правок не требуется

## Проблема (баг-репорт пользователя)

На кубике **d20** наблюдается белая полоса между гранями **12 и 6** и между гранями **14 и 9**.
Полоса находится где-то на ребре (граница двух граней). Гипотеза юзера — это баг, полосы быть не
должно; но нужно исследование: либо убрать полностью, либо «пофиксить», чтобы ребро было
явное/осознанное (если это фича оформления).

## Что сделать (исследование → вердикт → фикс)

1. **Визуально локализовать**: снять крупные скриншоты d20 (tmp/shots/…) — какие именно рёбра, видно
   ли на других размерах/ракурсах (только d20? d12/d8 чистые?). Номера граней 12/6 и 14/9 — сверить
   с раскладкой граней (модель `public/cad/set/d20.glb`, `src/entities/model/models.ts`).
2. **Веб-ресёрч**: d20 = икосаэдр — как выглядят рёбра у настоящего/цифрового d20 (Wikipedia
   «regular icosahedron» / d20-спека): у правильного икосаэдра ребро — это стык двух граней без
   фаски и без белой линии; белая полоса = либо фаска/бортик в CAD-модели, либо шейдинг-артефакт.
3. **Технические подозрения** (проверять в этом порядке):
   - шейдинг: `toCreasedNormals(geometry, CREASE_ANGLE)` (`src/shared/three/table.ts` L12, L211;
     `viewer.ts` L24, L582) — CREASE_ANGLE = π/5 (36°); углы между гранями икосаэдра ≈ 138.2°
     внутренние → нормали должны быть flat. Белая полоса на стыке может быть от сглаживания/двойных
     вершин/UV-шва;
   - сама геометрия d20.glb: открыть (Blender/глазами через чекер) — есть ли вдоль ребра тонкая
     боковая грань (фаска), которая светится белым;
   - материал/освещение: `specular`-блик ровно по ребру (env RoomEnvironment + DirectionalLight) —
     проверить, пропадает ли полоса при другом свете.
4. **Вердикт**: нужна ли полоса по канону d20 (скорее нет). Варианты фикса:
   - если геометрия (фаска) — поправить модель/пересобрать GLB (OpenSCAD/CAD-исходник смотреть в
     tasks/ mvp-1/DICE_TRAY — источник d20);
   - если шейдинг — подкрутить CREASE_ANGLE/нормали/ материал;
   - если оставить как декорат ребро — сделать осознанно (тоньше/ровнее/тень вместо белого
     свечения).
5. Реализация — после вердикта; приоритет низкий, не мешать основным задачам.

## Итог исследования

**Вердикт: фича оформления, не баг.** Полоса на рёбрах — честный блик на скруглении ребра,
заложенном в CAD. Правок кода/модели не требуется.

### Доказательства

1. **Геометрия — осознанное скругление.** Вдоль всех 30 рёбер d20 идёт скругление радиуса 1 мм:
   `EDGE_R = 1` в CAD-исходнике `tools/dice_set.scad`, тело — `hull()` из сфер. Из 6101 треуг. тела
   **2792 — фаска** (чекер: `node tmp/check/d20-shading.mjs viz` → `bevelTris=2792/6101`; картинка
   `tmp/shots/d20-stripe/lab/viz.png` — пурпуром по всем рёбрам).
2. **Шейдинг не при чём.** Нормали главных граней не сглаживаются: угол между нормалями смежных
   граней икосаэдра = 180° − 138.19° = **41.81°** > `CREASE_ANGLE` 36° (`table.ts` L12; лаборатория:
   `minAng=41.81`). При полностью flat-нормалях (`crease=0.5°`) полоса **сохраняется** —
   `lab/flat.png`. Значит, не артефакт `toCreasedNormals`, двойных вершин и не UV-шов.
3. **Полоса = блик (specular/env).** Гаснет при грубее поверхности — `lab/rough50.png`,
   `lab/rough70.png` — и почти исчезает при слабом env (`lab/no-env.png`, env=0.15; без rim не
   помогает — `lab/no-rim.png`). Материал `D_body`: roughness 0.35, metalness 0; свет —
   RoomEnvironment + key/fill/rim/under.
4. **Не специфика d20.** Та же полоса на рёбрах d6/d8/d10/d12 — `before-d8.png`, `before-d12.png`,
   `lab/d6-default.png`, `lab/d8-default.png`, `lab/d12-default.png`. Единый стиль набора, не
   локальный дефект.
5. **Канон d20.** Wikipedia (Dice → Manufacturing): precision dice — острые рёбра, non-precision —
   скруглённые/фаска, равномерное скругление допустимо; Regular icosahedron — внутренний дедральный
   угол 138.19°. Наш набор — обычные (не прексишен) кости: 1 мм на 17.5 мм (d20) — это ровно такой
   дизайн.

### Решение

Оставить как есть. «После»-скриншоты не нужны (визуальных правок нет) — «до» в
`tmp/shots/d20-stripe/before-*.png`, варианты — в `lab/`.

### Опционально: приручить блик (низкий приоритет, по желанию)

- Поднять roughness `D_body` 0.35 → ~0.5: сравнить `lab/default.png` (0.35), `lab/rough45.png` (0.45
  — почти без изменений), `lab/rough50.png` (0.5 — полоса заметно мягче, пластик ещё глянцевый),
  `lab/rough70.png` (0.7 — полосы нет, но кость уже матовая).
- Где править: материал зашит в `public/cad/set/*.glb` (пересборка
  `tools/blender-stl-colorize-set.py`) либо override после загрузки в `src/shared/three/table.ts` /
  `viewer.ts`. ~0.5–1 ч, проверить все кости.
