## Грамматика (нормативная)

```text
expr     := term (('+' | '-') term)*
term     := dice | number
dice     := [count] 'd' sides [suffix]
count    := 1..100 (пусто = 1)
sides    := 4 | 6 | 8 | 10 | 12 | 20 | 100
suffix   := ('kh' | 'kl' | 'dh' | 'dl') n | '-L' | '-H'
number   := целое [-999..999]
```

Правила:

- Пробелы игнорируются везде (`2d20 kh1 + 5` валидно).
- Регистр `d`/`D` и суффиксов — insensitive (`4D6-L` = `4d6-l`).
- `-L` ≡ `dl1` (бросить, убрать меньшую), `-H` ≡ `dh1`.
- `khN` — оставить N больших, `klN` — N меньших, `dhN`/`dlN` — убрать N больших/меньших.
  `0 < N < count`, иначе ошибка валидации.
- `d100` — грани 1..100 напрямую (физический d100 позже; в 2.5 появится пара d10+d%, парсер уже
  сейчас отдаёт `sides: 100`).
- Одиночное число — константа-модификатор (`+5`, `-2`).
- Пустая строка, `0d6`, `d7`, `2d6kh9`, `4d6-` — ошибки с текстом (какая позиция, что ожидалось).

## AST (контракт для 2.2 — не менять без согласования)

```ts
type DiceSides = 4 | 6 | 8 | 10 | 12 | 20 | 100
type KeepOp = 'kh' | 'kl' | 'dh' | 'dl'
interface DiceTerm {
  kind: 'dice'
  count: number // 1..100
  sides: DiceSides
  op: KeepOp | null
  opN: number // значим при op != null, 0 < opN < count
}
interface ConstTerm {
  kind: 'const'
  value: number
}
interface SignedTerm {
  sign: 1 | -1
  term: DiceTerm | ConstTerm
}
interface RollExpr {
  terms: SignedTerm[] // унарный минус первого терма разрешён
}
```

API:

```ts
parseNotation(input: string): RollExpr; // бросает NotationError
normalize(expr: RollExpr): string; // каноническая строка: '2d20kh1+5'
```

`NotationError extends Error` с полями `pos: number`, `expected: string`.

| `10d10kl2-4`   | `10d10kl2-4` | kl + отрицательная конст. |

Невалидное → `NotationError` (проверять `toThrowError(NotationError)`):

| Ввод     | Причина                                                              |
| -------- | -------------------------------------------------------------------- |
| ``       | пусто                                                                |
| `d`      | нет граней                                                           |
| `0d6`    | count < 1                                                            |
| `101d6`  | count > 100                                                          |
| `d7`     | нет таких граней                                                     |
| `2d6kh2` | N == count (нечего дропать/держать вне равенства: требуем N < count) |
| `2d6kh3` | N > count                                                            |
| `4d6-`   | висячий оператор                                                     |
| `+`      | нет термов                                                           |
| `2dd6`   | мусор после d                                                        |
| `kh1`    | суффикс без костей                                                   |

Плюс: normalize(parse(x)) === normalize(parse(normalize(parse(x)))) (идемпотентность) хотя бы на 5
примерах.
