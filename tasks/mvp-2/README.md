# MVP-2 «пул»: обзор среза

Цель среза: бросок пула костей одной формулой — степперы, формула-бар, 3 пресета, подсветка
kept/dropped, juice. После среза бабушкин тест: «Fireball 8d6 за <30 сек с первого экрана».

## Контекст (читать перед любой задачей среза)

- `docs/PLAN.md` — раздел «Трек A», Definition of Done среза.
- `docs/ARCHITECTURE.md` — куда класть код (парсер → `entities/dice-notation/`, пул →
  `features/dice-pool/`, UI → `widgets/roll-panel/`).
- `docs/UX_ROLL.md` §1–§2 — паттерны 1-vs-N, пресеты.
- Существующие сущности: `entities/dice-geometry/` (`DieId`, `faceValue`), `entities/roll-history/`,
  `features/roll-dice/` (стор, физика, readout).

## Глобальная приёмка среза

- Формула `4d6-L` бросает 4 кости, дропает меньшую, показывает сумму и части.
- Пресеты Advantage / Stats / Fireball работают в один тап.
- Результат читаем за ≤3 сек, 0 ошибок консоли (Playwright).
