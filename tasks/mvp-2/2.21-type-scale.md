# 2.21 Инверсия типографской шкалы: мобила крупнее, десктоп плотнее (вариант A)

Статус: DONE (реализация и проверки 2026-10-06; коммит по просьбе пользователя)

## Задача от пользователя

Инвертировать типографскую шкалу 2.19-фазы 2: сейчас рост шёл в сторону десктопа (+0.35vw к
потолку), а по конвенции mobile-UI щедрее, широкие экраны — плотнее. Варианты обсуждали через
question tool; выбран **вариант A** — инверсия без пересчёта токенов: те же 6 `--fs-*` и 6
`--icon-*`, но мобила получает max, десктоп — min.

## Ресёрч (конвенция)

- Мобильные дизайн-системы (Material Type Scale, Apple HIG) делают базовый шрифт на телефоне
  крупнее, а на десктопе — плотнее (dense UI): мелкий текст на широком экране читается так же, но
  экономит строку, мелкий на телефоне — не читается.
- Fluid type (web.dev): `clamp(min, preferred, max)`; для **нисходящей** шкалы preferred спадает с
  ростом viewport и на широких экранах упирается в min.
- Старое поведение 2.19-фазы 2 (восходящий `+0.35vw`, потолок ~1570px) — частично откатывается:
  оставалось полы под телефоны, но рост был не туда.

## Реализация

- `src/widgets/mobile-table/mobile-table.css`, блок токенов `body[data-mode='mtable']` (комментарий
  в коде переписан):
  - формула убывающего clamp: **`clamp(D, (M + 1.28) − 0.32vw, M)`** — M = мобильный cap, D =
    десктоп = M − 2;
  - расчёт: до ~400px средняя выше M → работает мобильный max; `0.32vw` спадает с ростом экрана и на
    **1024px** (0.32 × 10.24 = 3.2768 ≈ 3.28) даёт ровно M − 2 = D; дальше — фиксированный
    десктопный min, без дальнейшего роста;
  - итог: `--fs-cap` 15 → 13, `--fs-meta` 16 → 14, `--fs-sec` 17 → 15, `--fs-body` 18 → 16,
    `--fs-title` 19 → 17, `--fs-headline` 21 → 19 (мобила → десктоп);
  - иконки — та же инверсия и тот же спад `0.32vw` (был восходящий `0.4vw`): `--icon-head` 26 → 24,
    `--icon-like` 18 → 16, `--icon-chip` 20 → 18, `--icon-glyph` 30 → 28, `--icon-wide` 24 → 22,
    `--icon-row` 28 → 26 (Δ2);
  - всё по-прежнему умножается на `var(--ui-scale)` (2.20), 3D-кости не трогаем.

## Проверки

- `tmp/check/type-scale.mjs` переписан под инверсию: формульная ожидание ±0.2px, на телефоне токены
  = max, на десктопе = min, середина — спад по `vw`; проверки потолка (~1024px, дальше значения не
  растут). Первый прогон дал 3 FAIL — flaky (шёл по границе порога), повторные 2 прогона — **ALL
  OK**, больше не воспроизводились.
- Полный прогон перед коммитом: `npm run lint`, `npm test`, `npm run test:e2e`, чекеры `ui-scale`,
  `add-icon`, `hint-v2`, `hint-cta2-shots`, `social-shots`, `hint-align`, `like-fit-probe` — **все
  ALL OK** (запускались после правки CSS).
