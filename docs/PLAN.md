# PLAN: реализация по MVP — задачи, файлы, приёмка

Дата: 2026-09-22. Статус: MVP-1 ГОТОВ (все 7 задач, E2E зелёный). Источники требований: UX_ROLL.md
(срезы), BUSINESS.md (границы), ARCHITECTURE.md (куда класть код), AUDIO.md (звук), I18N.md (EN/RU).
Глобальный Definition of Done каждого среза: `tsc` чисто, ESLint чисто, `npm test` зелёный,
Playwright-чек (0 ошибок консоли, панели/модели на месте), `npm run build` ок, коммит с хуками.

## MVP-1 «бросок» (1–2 сессии)

Цель: тап по кости = физический бросок, крупный результат, история. Критерий бабушки: d20 за <30 сек
с первого экрана; результат читаем за ≤3 сек.

Вне скоупа MVP-1: пулы, нотация, пресеты, темы, шаринг, PWA-упаковка, TMA.

## MVP-2 «пул» (следом)

1. Парсер нотации `4d6-L`, `2d20kh1+5`, `d100` → `entities/dice-notation/` + тесты (таблица:
   валид/невалид, kh/dl, модификаторы).
2. Степперы количества + формула-бар + 3 пресета (Advantage, Stats `4d6-L`, Fireball `8d6`) →
   `features/dice-pool/`, UI в `widgets/roll-panel/`.
3. Подсветка kept/dropped при advantage, сумма + разбивка по костям.
4. Slow-mo nat20/nat1, конфетти на крит, скриншейк ∝ числу костей (UX_ROLL §3).
5. Решение default-инпута (пикер vs формула) — только по данным аналитики.

## MVP-3 «PWA + языки»

1. `vite-plugin-pwa` (Workbox): precache сет+движок (~5 МБ), офлайн-бейдж, экран «добавить на
   домой», иконки+маска.
2. i18n EN/RU (I18N.md): `/locales/*.json`, `navigator.language` + оверрайд, `Intl.PluralRules`,
   псевдолокаль-тест; сабсеты шрифтов (cyrillic/latin-ext!).
3. Темы материалов (скины D_body/D_pips + localStorage).
4. TMA-адаптер `src/shared/telegram/` (BUSINESS.md §5.1) — fast-follow.

## Порядок и зависимости

```text
MVP-1 (1.1 → 1.2 → 1.3 → 1.4 → 1.5) → 1.6 + 1.7 параллельно
   └─▶ MVP-2 (нотация → пул → juice) ─▶ MVP-3 (PWA → i18n → темы → TMA)
```

cannon-es уже в dependencies — ставить ничего не надо. Новый код — только по ARCHITECTURE.md
(таблица «куда класть»), тесты рядом с логикой.
