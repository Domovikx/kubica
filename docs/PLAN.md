с первого экрана; результат читаем за ≤3 сек.

## MVP-2 «пул» (следом)

1. Парсер нотации `4d6-L`, `2d20kh1+5`, `d100` → `entities/dice-notation/` + тесты (таблица:
   валид/невалид, kh/dl, модификаторы).
2. Степперы количества + формула-бар + 3 пресета (Advantage, Stats `4d6-L`, Fireball `8d6`) →
   `features/dice-pool/`, UI в `widgets/roll-panel/`.
3. Подсветка kept/dropped при advantage, сумма + разбивка по костям.
4. Slow-mo nat20/nat1, конфетти на крит, скриншейк ∝ числу костей (UX_ROLL §3).
5. Решение default-инпута (пикер vs формула) — только по данным аналитики.

## MVP-3 «PWA + языки»

1. `vite-plugin-pwa` (Workbox): precache сет+движок (~5 МБ), офлайн-бейдж, экран «добавить на
   домой», иконки+маска.
2. i18n EN/RU (I18N.md): `/locales/*.json`, `navigator.language` + оверрайд, `Intl.PluralRules`,
   псевдолокаль-тест; сабсеты шрифтов (cyrillic/latin-ext!).
3. Темы материалов (скины D_body/D_pips + localStorage).
4. TMA-адаптер `src/shared/telegram/` (BUSINESS.md §5.1) — fast-follow.
