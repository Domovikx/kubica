# UX броска: 1-vs-N, MVP, залипательная анимация, хуки

Дата: 2026-09-22. Статус: ресёрч для обсуждения и разработки по MVP.
Канон жанра «сочности» (game feel): доклад *Juice it or lose it*
(Jonasson & Purho, 2012), книга *Game Feel* (Swink). Референс-конкурент
по физике броска: модуль Dice So Nice! для FoundryVTT.

## 1. Переключение «1 кубик vs N кубиков»: паттерны

Четыре паттерна ввода (все нужны, вопрос — какой по умолчанию):

| Паттерн | Пример | Когда удобен |
|---|---|---|
| A. Пикер + степпер | тап d20 → `+`/`−` количество | новички, тач-интерфейс |
| B. Формула | `4d6-L`, `2d20kh1+5` | опытные, скорость |
| C. Пресеты | «Advantage», «Fireball 8d6», «Stats 4d6-L» | частые кейсы D&D |
| D. История → реролл | тап по прошлой записи | повторы, проверки DM |

**Что спросить у пользователей (опрос + интервью):**
1. Как выбираете кости: по одной / формулой / пресетом? (ранжирование)
2. Как часто пул из >1 типа за раз (напр. `d20+d6` урон)? А из >3 костей?
3. Нужны ли именованные броски («Sneak Attack»)? Сколько пресетов хватает?
4. Модификаторы: кнопки +1/−1 или клавиатура/поле ввода?
5. Что должно произойти после броска: только сумма / сумма + каждая кость /
   подсветка max-min (advantage)?

**Аналитика (события, без персональных данных):**
`die_added{type}`, `pool_size`, `formula_used`, `preset_used{name}`,
`reroll_from_history`, `modifier_changed`. Решение по умолчанию (A vs B)
принимаем по долям через 2–4 недели после MVP.

## 2. Разработка по MVP (каждый срез — шиппабельный)

- **MVP-1 «бросок»**: один канвас уже есть → тап по кости = физический бросок,
  крупный результат (наш `.result`-поп уже есть!), история в localStorage.
  Критерий готовности: бабушка бросает d20 за <30 сек с первого экрана.
- **MVP-2 «пул»**: степперы + формула с парсером + 3 пресета
  (Advantage / Stats / Fireball) + история с рероллом.
- **MVP-3 «PWA»**: `vite-plugin-pwa`, офлайн-бейдж, установка, i18n EN/RU,
  темы материалов.
- **Дальше:** шаринг карточек результата → кастомайзер → STL-экспорт
  (см. BUSINESS.md §7, §9).

## 3. Залипательная анимация броска (ресёрч техник)

Ограничение честности: анимация — только презентация; исход определяет
крипто-RNG, физика обязана уметь выкинуть любое значение (никаких
«подкруток под результат»). Бюджет: бросок → читаемый результат за ≤2–3 сек,
иначе juice бесит при 50-м броске за вечер.

| Техника | Эффект | Цена | Статус |
|---|---|---|---|
| Rattle-шейк перед броском (anticipation) | предвкушение | дёшево (камера/звук) | в MVP-1 |
| Звук: грохот с питчем от скорости + глухой «ток» остановки | 50% «залипания» | WebAudio, 0 ассетов извне (синтез) | в MVP-1 |
| Вибрация на остановке; двойной паттерн на крит | тактильность | `navigator.vibrate`, бесплатно | в MVP-1 |
| Долли-камера к верхней грани + scale-pop цифры (наш `.result` уже так умеет) | фокус результата | дёшево | в MVP-1 |
| Slow-mo 0.25× на nat20/nat1 | драма | легко (timeScale физики) | MVP-2 |
| Конфетти-частицы на крит | награда | Points/InstancedMesh, дёшево | MVP-2 |
| Screen shake ∝ числу костей | вес | одна строка на камеру | MVP-2 |
| Idle-притяжение (медленный автоповорот уже есть) | витринность | 0 | уже есть |

**Движок физики:** `cannon-es` для MVP — чистый JS (без WASM-инициализации,
идеален для офлайн-PWA), стабилен, выпуклых костей хватает с запасом
(ConvexPolyhedron из вершин hull). `rapier` — если позже понадобятся сложные
сцены; тяжелее и асинхроннее. Детерминизм: фиксированный timestep + сид —
тогда можно гонять chi-square на 10к сим-бросков в CI и **публиковать**
результат как доказательство честности (уникальная фишка, см. BUSINESS.md §1).

## 4. Что ещё привлечёт к продукту (хуки)

- **Шаринг карточек результата** (снапшот канваса → картинка в Discord):
  вирусный цикл из коробки.
- **Прогрессия без монетизационного давления:** темы/цвета открываются за
  число бросков (не за деньги) — «накрути 100 бросков → лава-сет».
- **Виджет/шорткат Android** «кинуть d20 в один тап» с домашнего экрана.
- **Звуковые паки** (дерево/металл/казино-фетр) — дешёвый дофамин.
- **Онбординг 3 шага:** выбери кость → тапни → вот твой результат + история.
- **НЕ делаем:** стрик-награды в духе гемблинга, лутбоксы, «удачливые» кости
  за деньги (убивает позиционирование честности, BUSINESS.md §7).
