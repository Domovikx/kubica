Проверенный факт из страницы DSN, важный для нас: их стек — **Three.js + cannon-es** (тот же, что

(zapsplat), у нас будут синтез (см. AUDIO.md — лучше для офлайна).

## 2. Что скопировать (паритет фич)

По приоритету, всё уже частично есть в наших доках:

1. **Темы/пресеты на кость** (цвета, материалы, шрифты) — UX_ROLL.md §4, скины.
2. **Спецэффекты по условиям** (nat20/nat1, kept die, взрывы) — UX_ROLL.md §3, AUDIO.md
   (фанфары/стон).
3. **Редактор дайсов** (свои лейблы/глифы на гранях) — долгая цель; у нас задел лучше их:
   параметрический генератор + гравировка уже есть, им до CAD-точности далеко.
4. **Звуки** — у них ассеты, у нас синтез (дешевле и офлайн).
5. **API для разработчиков** — позже (сначала свой MVP-1).

## 3. Что НЕ копировать

- Привязку к чужой платформе (мы — standalone PWA + TMA-оболочка).
- Рекламу, прерывающую бросок (см. ниже).
- AGPL-код тащить нельзя (мы clean-room; их лицензия заразительна для производных — даже смотреть
  только API/доки, не исходники).

## 4. Ров (что им трудно скопировать)

1. **Честная геометрия как бренд:** открытые CAD-модели + опубликованные замеры CoM (RESEARCH.md
   §6) + будущий chi-square симов в CI. Скопировать можно, но «первый с доказательствами» — мы.
2. **Офлайн-PWA без аккаунта:** у всех конкурентов — либо экосистема, либо реклама, либо онлайн.
3. **Замкнутый цикл «кастом → STL → печать»:** генератор уже в репозитории; ни у кого из таблицы
   этого нет.
4. **i18n TOP-10 + a11y из коробки:** конкуренты почти все EN-only.

## 5. Вход: да, бесплатный user-friendly. Почему это правильно

- Кости — социальный объект: партию видно бросок → каждый увидевший — потенциальный пользователь.
  Трение убивает виральность, поэтому: **все броски, все кости, офлайн — бесплатно навсегда, без
  аккаунта.**
- Конкуренты монетизируют боль (подписка D&D Beyond, реклама в апплетах, $50 Foundry) — мы заходим
  через «просто лучше и чисто».
- Деньги — только с необязательного (см. BUSINESS.md §7): кастом-материалы, гравировка имени,
  STL-коммерция, print-on-demand %, аффилиаты, донаты. Принцип-фильтр любой фичи монетизации:
  «прерывает ли это бросок?» Если да — не делаем.

## 6. Воронка забора аудитории (как именно)

1. **Инлайн-броски в TG-чатах партий** (TMA, BUSINESS.md §5.1) — видят все, ставят себе.
2. **Шаринг карточек результата** в Discord (UX_ROLL.md §4) — то же для EN.
3. **SEO-контент, которого нет у конкурентов:** «мы посчитали центр масс кубиков», CAD-ресёрч,
   per-die страницы (BUSINESS.md §8).
4. **Реддит/нишевые комьюнити:** r/dndnext, Foundry-Discord («а вот standalone без хоста»), Pikabu.
5. **Мейкеры:** STL-экспорт → Thingiverse/Printables с ссылкой назад.
