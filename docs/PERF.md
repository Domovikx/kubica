# PERF: стек, экономия ресурсов, мобилы и батарея

Дата: 2026-09-22. Статус: ресёрч + замеры текущей страницы просмотра. Цель: держать 60 fps на
среднем железе и не садить батарею.

## 2. Главная архитектурная проблема: N рендереров

Сейчас `createViewer` = 1 canvas + 1 `WebGLRenderer` + 1 PMREM/RoomEnvironment

- 1 shadow map **на каждую панель**. При 9 панелях: 9 контекстов, 9 компиляций шейдеров, 9 проходов
  теней. Мобильные браузеры держат ~8–16 контекстов — мы упираемся в лимит, дальше чёрные панели и
  `webglcontextlost`.

Рекомендация (по приоритету):

1. **P0 — потолочные меры без рефактора:** лимит панелей (на мобиле max 4?), тени 1024 на слабом
   железе, `powerPreference` уже стоит.
2. **P1 — один рендерер + scissor viewports** (официальный паттерн three.js
   `webgl_multiple_elements`): 1 контекст, 1 компиляция шейдеров, 1 shadow map, N видов через
   `setViewport/setScissor`. Это главный выигрыш, но рефактор `d20.ts` (канвасы → один canvas +
   прозрачные панели-окна).
3. **P2 — общий PMREM/env** даже при N рендерерах (сейчас каждый печёт свой).

## 3. Lazy loading (что грузить когда)

- **three.js в главном бандле — правильно:** вьювер нужен на первом экране.
- **Физика бросков (будущее): `cannon-es` через `dynamic import()`** — чистый JS, без
  WASM-инициализации (в отличие от rapier): идеален для PWA-офлайна, грузится только при первом
  броске. Rapier — если позже понадобятся сложные сцены.
- **GLB:** сет (~3 МБ) — precache Workbox; trio сравнения (22 МБ!) — строго on-demand по выбору
  чекбокса, плюс `Cache-Control: immutable` + версионирование.
- **Шрифты/темы/звуки:** лениво по требованию (звуковые паки — только после первого тапа, требование
  автоплея браузеров и так это навязывает).
- **Draco/meshopt:** НЕ сейчас — декодер +100 КБ WASM и асинхронность ради экономии, которая нам не
  нужна (модели и так мелкие, кроме trio).

## 4. Resize: правильно

Сейчас `window.resize` — хватает, но хрупко (сайдбар, devtools, поворот). Правильно:
`ResizeObserver` на контейнере `.viewers` → `resize()` всех активных вьюверов. Дешёво, один раз.

## 5. Батарея: главный пожиратель — вечный rAF

Сейчас каждая панель крутится всегда (autoRotate + тени каждый кадр). Лестница мер (от дешёвого к
дорогому):

1. **`document.visibilitychange` → стоп loop скрытой вкладки** (rAF и так троттлится, но явно —
   надёжнее). ~5 строк.
2. **`IntersectionObserver` на панели → не рендерить вне экрана** (актуально при скролле на мобиле).
   ~20 строк.
3. **`prefers-reduced-motion` → выключать autoRotate** (a11y + батарея). 3 строки.
4. **Idle-таймаут автоповорота:** 10 сек без взаимодействия → стоп, тап — resume. Витринность
   сохраняется, простой не жрёт батарею.
5. **Render-on-demand:** рендерить кадр только при `controls.change` / анимации броска. Максимум
   экономии, но трогает ядро цикла — после P1.
6. **Эко-режим (переключатель Качество/Эко):** pixelRatio 1, тени off, FPS-cap 30 через пропуск
   кадров. Для слабых Android.

## 6. Мобилы: граничные случаи

- **Лимит контекстов (iOS Safari ~8):** 9 панелей = чёрный экран. До рефактора P1 — кап панелей на
  тач-устройствах (`matchMedia('(pointer: coarse)')` → max 4)
  - слушатель `webglcontextlost` с оверлеем «переоткройте панель».
- **Thermal throttling:** длинные сессии роняют частоту — адаптивное разрешение (лестница pixelRatio
  2 → 1.5 → 1 по скользящему FPS) держит отзывчивость.
- **DPR 3 (iPhone Pro):** кап 2 уже стоит — правильно, выше только мыло за кадры.
- **Память:** dispose при снятии чекбокса уже есть; добавить гард на drag&drop чужого `.glb` (лимит
  ~50 МБ, иначе OOM на телефоне).
- **PWA + Safari:** precache держать ≤25 МБ (влезаем: ~4 МБ), иначе эвикт кэша.
- **Фон:** сворачивание PWA — loop стоп (п.5.1), контексты не убиваем (восстановление дороже).

## 7. Графика: что крутить, что нет

- Тени 2048→1024 на мобиле: −4× памяти/филлрейта, визуально почти то же.
- MSAA (`antialias`) оставить: главный вклад в «чистоту» рёбер цифр.
- ACES + IBL: почти бесплатно (PMREM запечён), не трогать.
- Пост-эффекты (bloom/SSAO): НЕТ — дорого и не нужно для матовых костей.
- `toCreasedNormals` при загрузке: разовая цена, ок (187к тр. FreeCAD — ~0.5с).

## 8. Как мерить (чтобы не гадать)

- `?debug=fps` — dev-оверлей FPS/средний кадр (только в dev, не в прод).
- Playwright: ассёрт «0 ошибок консоли + все панели в вьюпорте» уже есть; добавить бюджет «первый
  кадр < 3с на 3G».
- Lighthouse CI: Performance ≥90, Best Practices, PWA installable.
- Реальные девайсы: 1× средний Android + 1× iPhone перед релизом PWA.

## 9. Бэклог внедрения (порядок)

- **P0 (дешево, сейчас):** visibilitychange-стоп, prefers-reduced-motion, ResizeObserver, гард
  размера drag&drop-glb, trio GLB — on-demand лейбл.
- **P1 (рефактор):** один рендерер + scissor (убивает проблему контекстов и 9× теней разом).
- **P2 (адаптив):** лестница pixelRatio по FPS, эко-переключатель, idle-стоп автоповорота,
  IntersectionObserver-пауза.
- **P3 (позже):** physics lazy (`cannon-es` dynamic import), шаринг геометрии одинаковых моделей
  между панелями, Draco — только если модели распухнут.
